## 2. المكتبات الخارجية (SDKs) والاتصال بالخدمات السحابية

* **التحقق من الاتصالات الخارجية بالشبكة (Network Egress Check)**:
  * تم فحص ملفات المشروع (`src/App.tsx`, `src/main.tsx`, `index.html`, `package.json`):
  * **مكتبات التتبع والإعلانات (Analytics / Ads)**: **غير موجودة مطلقاً** (لا وجود لـ Google Analytics أو Firebase Analytics أو Mixpanel أو Facebook Pixel).
  * **الخطوط الخارجية**: يتم استدعاء خطوط Google Fonts عبر CDN (`fonts.googleapis.com` و `fonts.gstatic.com`) لتحميل خطي "Cairo" و "Tajawal". هذا الاتصال الوحيد الصادر من المتصفح في نقطة الدخول `index.html`.
  * **الاتصال بالخوادم الخلفية (Backend APIs)**: لا يوجد أي اتصال شبكي بخادم خلفي أو واجهة API خارجية؛ التطبيق يعمل كلياً بدون اتصال خادمي Client-Side Only.

## 3. فحص ومراجعة الذكاء الاصطناعي (AI Data Ingestion Check)

* **التصريح المنصوص عليه**: تتضمن وثيقة `metadata.json` البند:
  ```json
  "majorCapabilities": ["MAJOR_CAPABILITY_SERVER_SIDE_GEMINI_API"]
  ```
* **الفحص البرمجي للأدلة**:
  * تم إجراء فحص معمق بكافة ملفات المشروع بحثاً عن أي استخدام لـ `@google/genai` أو استدعاء لـ `https://generativelanguage.googleapis.com` أو دالة ترسل استعلامات لنموذج ذكاء اصطناعي.
  * **النتيجة القاطعة**: **لا يتم إرسال أي حرف أو اسم أو بيان من بيانات المستخدم أو الطفل إلى أي نموذج ذكاء اصطناعي نهائياً**.
  * **التوصية**: لا توجد مخاطر خصوصية متعلقة بالذكاء الاصطناعي في التنفيذ الحالي، لكن ينبغي تصحيح `metadata.json` بإزالة التصريح غير المستخدم تجنباً للتضليل الرقابي.

## 4. سياسة الصلاحيات والأدوار (Roles & Parental Controls)

* **الأدوار (Role-Based Access Control)**:
  * **غير موجودة**: لا يوجد نظام حسابات مستخدمين، ولا تسجيل دخول، ولا تفريق بين صلاحيات طفل (Child)، ولي أمر (Parent)، أو مشرف (Educator/Admin).
* **إمكانية التعديل والحذف**:
  * أي شخص يفتح المتصفح يمتلك حق الوصول الكامل لكافة البيانات المدخلة وتعديلها أو حذفها.
  * لا توجد بوابة حماية أو رمز دخول (Parental PIN) لحماية البطاقات المحفوظة من الحذف العبثي من قبل الأطفال الصغار.

## 5. سياسة الحذف والاحتفاظ بالبيانات (Data Deletion & Retention)

* **آلية الحذف المتوفرة في الواجهة**:
  * يتوفر زر حذف أحمر بجانب كل بطاقة مكرمة في شاشة «كرّم بطلك» عبر دالة `handleDeleteHonored(id)`:
    ```typescript
    const handleDeleteHonored = (id: string) => {
      const updated = honoredHeroes.filter(h => h.id !== id);
      setHonoredHeroes(updated);
      localStorage.setItem('honored_heroes', JSON.stringify(updated));
    };
    ```
  * هذا الزر يمسح البطاقة فورياً من مصفوفة الحالة ومن مفتاح `honored_heroes` في `localStorage`.
* **الفجوات في إدارة البيانات**:
  * لا يوجد خيار «حذف جميع البيانات بنقرة واحدة» (Reset All App Data).
  * لا توجد آلية لتصدير البيانات (Export as JSON) لحفظ نسخة احتياطية من البطاقات والمهام قبل مسح المتصفح.
  * مسح تاريخ المتصفح أو مسح ذاكرة التخزين المؤقت (Clear Browsing Data) يؤدي لفقدان دائم لا رجعة فيه لكافة البطاقات ونقاط المهام.
